# AI Story Weaver
A collaborative AI app that helps users co-write stories while maintaining characters, plot, and tone.
## Features
- Collaborative story writing with AI
- Maintains full story context
- Supports multiple genres and tones
- Fast AI-powered story generation
- ## Installation
1. Clone the repo: `git clone https://github.com/YourUsername/AI-Story-Weaver.git`
2. Create a virtual environment: `python -m venv venv`
3. Activate the environment: `source venv/bin/activate` (Windows: `venv\Scripts\activate`)
4. Install dependencies: `pip install -r requirements.txt`
5. Add your Groq API key in a `.env` file
6. Run the app: `streamlit run app.py`
7. ## Usage
1. Open the app in your browser
2. Choose a story genre and enter a starting prompt
3. AI generates the next part of the story
4. Continue collaborating with the AI
5. ## Tech Stack
- Python + Streamlit for the app
- Groq API for AI story generation
- Optional: Docker / Cloud deployment
